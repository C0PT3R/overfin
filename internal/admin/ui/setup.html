TMDB Optional

TMDB is where Overfin gets titles' names, synopses, artwork and ratings, in your languages, and what to discover. It's free; you need a key of your own, once.

  1. Create a TMDB account, and confirm its email.
  2. In your account's Settings → API, ask for a developer key: personal use is fine.
  3. Copy the API key or the API Read Access Token, and paste it here.

Skipped, Overfin runs on what Jellyfin knows: fewer details, no ratings for kids profiles, no discovery. You can add a key later in the control panel.

Intro Skipper Optional

A Jellyfin plugin that finds each episode's intro and credits, so the player offers "Skip intro" and "Skip credits", and goes to the next episode sooner.

Overfin adds its repository to its Jellyfin, installs version 12.0.5.0 (the one Overfin is tested with, checked before it's installed), and restarts Jellyfin. It takes under a minute. Episodes are then analysed in the background.

It's made by the Intro Skipper project, not by Overfin or Jellyfin.

Requests, with Seerr Optional

With Seerr, people can ask for titles you don't have; with Radarr and Sonarr behind it, those titles arrive by themselves. Overfin gives each account its own Seerr user, and sends their requests through it.

  1. Install Seerr and run its setup, with a Jellyfin that sees the same media: another one, or Overfin's own once you open its access in the control panel.
  2. In Seerr, connect Radarr and Sonarr: they fetch what's requested.
  3. In Seerr, set what new users may do: permissions, auto-approval, limits. Every account gets those.
  4. Give Overfin Seerr's address and its API key (in Seerr's settings, under General).

You can connect it later in the control panel.
